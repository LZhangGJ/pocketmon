#### Message 3503673 — unknown

Posted: 2026-07-26T08:45:46.257Z

Our current online version (V6) relies purely on behavioral cloning backed by multiple hard-coded rules, with no value head implemented.The legacy V5 attempted to train V(s) using endgame win/loss outcomes (+1/-1) as a unified global value label. Dense auxiliary tasks such as attack chain prediction and KL constraints were introduced to mitigate reward sparsity. While the value head managed to learn a rough ranking of game outcomes (with a correlation coefficient of approximately 0.5–0.67), it failed to reliably judge which action was superior.Subsequent experiments further validated that reward shaping using intermediate events like D2/D3 could reduce breakage rates (for instance, D2 dropped from 18.78% to 17.71%), yet delivered zero net improvement in final win rate. The value signal could characterize hazardous states, but could not attribute risks to specific actions.Key conclusions:V(s) only captures state-level risks rather than action values, making scalar value heads unsuitable for direct decision guidance.All attempts to inject causal reasoning via auxiliary labels, reward shaping, or single-action replacement ended in failure. This arises because the base model internalizes statistical correlations instead of causal logic.The only viable path forward is to learn action-conditioned value Q(s,a). We intend to leverage counterfactual branching (Search API) to directly evaluate the long-term consequences of each action alongside uncertainty estimation, rather than continuing to assign the identical endgame label indiscriminately to all actions.

I read the AlphaGo paper, and it explained that combining tree search with policy and value-network evaluations works better than relying on either approach alone. This is especially relevant to TCGs because, unlike perfect-information games, they involve incomplete information. Tree search is therefore important for making the agent’s decision-making more rational, while the policy and value heads help it account for what may happen over the next few turns.
