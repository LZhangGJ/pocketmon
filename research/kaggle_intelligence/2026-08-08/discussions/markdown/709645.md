# 本文

PokeCa ABC の開催をきっかけに多くの方が初めて Kaggle の世界に来てくれました。Kaggle コミュニティとして本当にうれしく思います。

ただし Kaggle には、知る・知らないに関わらず、抵触すると失格もしくはアカウント停止につながるようなルールがいくつかあります。  
[**訳注**：参加者はコンペティションにエントリーする時点で[ルール](https://www.kaggle.com/competitions/pokemon-tcg-ai-battle/rules)に同意しているはずですが、Kaggle に不慣れな場合は意識から抜けてしまうことがしばしばあります。]    

コミュニティとしては皆さんに最後まで安心してコンペティションを楽しんで頂きたいので、本投稿では初参加者向けに特に気を付けて欲しいポイントをまとめました。どれも簡単な内容なので、ぜひご一読ください。

## 1. "private sharing" にご注意ください

Kaggle のコンペティションで最もトラブルの種になるのが "private sharing" です。考え方はとてもシンプルで：

> **コンペティションの内容に関わること(アイデア、コード、戦略、デッキ構築、... etc.) を共有する際の選択肢は、「全員に共有する」か「誰とも共有しない」のどちらかしかありません。特定の少人数の中でこっそりと共有することは認められていません**。

[**訳注**: 他には Leaderboard で対戦しているエージェント群をメタに分析した結果など(いわゆる対戦環境の分析)も対象です。ここでの「全員」というのはコンペティションの参加者全員を指しています。また、「誰とも共有しない」と書いていますが、Kaggle のシステム上で組んだチームメンバー内での共有は勿論問題ありません。]

このルールは、コンペティションで有利になる情報を一部のグループだけが独占し、不公平な状況が生じることを防ぐために設けられています。

### OK な例
*  **自分のエージェントのスコアや順位**を共有すること。例：「○○位まで来たぞ！」「自己べスト更新じゃい！」
* 「このコンペめっちゃ楽しい！」といった感想を共有したり、お互いを応援し合ったりすること
*  コンペティションの仕様や公開されている情報について、一般的な質問や雑談をすること

### NG な例
* **アイデアやデッキレシピ等を**、ダイレクトメッセージやチーム外のチャット（Discord、LINEなど）で**特定の人にだけ**伝えること
* チームメンバーではない相手と、ひそかに戦略を教え合うこと
* 「ここだけの話」として、限られた友人グループにだけ戦術をこっそり伝えること

重要なのは、**「こっそりと、限られた相手にだけ(共有する)」という部分がルールに抵触する**ということです。順位やスコアを共有すること自体は問題ありませんが、自分のアプローチの中身(アイデアやレシピなど)を特定の少人数だけに伝えることはルール違反になります。

### 有用な情報はぜひ Kaggle の Discussions に投稿してください！

ここで誤解して欲しくないのは、**「情報共有そのものが悪い」わけではない**ということです。むしろ全く逆であり、**Kaggle 上でのオープンな情報共有は歓迎・推奨されています**。事実 Kaggle の公式ルールでも、情報を共有するのであれば、すべての参加者の利益になるように Kaggle の Discussions もしくはNotebooks での共有が推奨されています。誰でも見られる場所で共有するのであれば、何の問題もありません。  
[**訳注**: 「誰でも見られる場所」は単にアクセス可能というだけでなく、参加者全員が把握している場所ということです。]

良いアイデアや有益な知見があれば、ぜひ Kaggle の Discussions に投稿をお願いします。コミュニティ全体が活性化しますし、メダルの獲得(後述)につながる可能性もあります。

一方で、以下の点にも気を付けてください：

* **X(旧 Twitter) 、ブログ、その他 Kaggle の外での情報共有は望ましくありません。** これらの媒体はすべての参加者が公平に見ることが出来ないので、「参加者全員と共有する」というルールを満たしていないからです。有益な情報は外部のプラットフォームではなく Kaggle Discussions で共有することを心がけましょう。    
    [**訳注**: 「鍵をかけていないXアカウントや公開ブログはオープンなのでは？」という意見もあるかもしれませんが、参加者全員があなたのXアカウントやブログ等を把握しているわけではありません。]

* **ただし、終了日の1週間前から情報共有を控えてください（これはコンペティションにおける一般的なルールあるいはエチケットです）。** 終盤の情報共有は順位に大きな影響を与え、公平性を損なう可能性があります。

迷ったら、公式ルールを確認するかコンペティションの運営側(ホストあるいは Kaggle チーム)に問い合わせましょう。―― それが安全な立ち回りです。

## 2. 複数のアカウントを使ってはいけません

**1人につき1アカウント — これが原則です。**

サブアカウント (2つ目/別 のアカウント) を使って：

* 順位を操作する、
* 本来許されている数(1日あたり5回)を超える提出を行う、
* 不当にメダルや賞金を狙う、

といった行為は全面的に禁止です。発覚すればアカウント停止や失格処分となる可能性があります。これは一時的なものではなく、長期間にわたってKaggleアカウントに影響を及ぼす重大なペナルティなので、絶対にやめましょう。「少しだけなら...」などというおかしな望みは捨ててください。

[**訳注**: ここでは複数のアカウントを1人で使うことについて述べていますが、 「1人につき1アカウント」なので、1つのアカウントを複数人で使うこともルールで明確に禁止されていることにご注意ください。]

## 3. 賞金とメダルについて — コンペティションの二つの部門の違い

PokeCa ABC には「シミュレーション部門([The Pokémon Company - PTCG AI Battle Challenge **Simulation**](https://www.kaggle.com/competitions/pokemon-tcg-ai-battle))」と「戦略部門([The Pokémon Company - PTCG AI Battle Challenge **Strategy**](https://www.kaggle.com/competitions/pokemon-tcg-ai-battle-challenge-strategy))」の2つの部門があります。**獲得できるものが部門ごとに異なる**ため、自分が何を目指すのか明確にしておくとよいでしょう。
  

| 部門 | メダル | 賞金 |
|----------|---------|------|
| シミュレーション | あり | なし |
| 戦略 | なし | あり |

　  
**シミュレーション部門**で獲得したメダルは蓄積され、Kaggle全体でのランキング向上や称号(Expert/Master など)の獲得につながります。これはKagglerとして長く残る成果です。一方でこの部門に賞金はありません。

**戦略部門**にメダルはありませんが、賞金を獲得することができます。

大まかに言うと: 

* 「ランキングや称号を伸ばしたい」→ シミュレーション部門に参加
* 「賞金獲得を目指したい」→ 戦略部門に参加

ということになります(もちろん両方に挑戦することも歓迎です)。なお、賞金の受け取りには本人確認などの条件が伴う場合があるため、詳細については公式ルールのページをご確認ください。

[**訳注**: [戦略部門の概要](https://www.kaggle.com/competitions/pokemon-tcg-ai-battle-challenge-strategy/overview)に記載されていますが、戦略部門に参加するためにはシミュレーション部門にも参加することが必須条件となっています。逆に、シミュレーション部門だけに参加するのであれば戦略部門に参加する必要はありません。]
