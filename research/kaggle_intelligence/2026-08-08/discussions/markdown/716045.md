Hey all

A few quick announcements as we head into a long holiday weekend here in the US:

1. The simulation environment has been updated, including an update to the sample submission (\`sample\_submission.zip\` on the \`Data\` tab).   
   1. Dataset update:  
      1. Update: cg library now supports macOS and Linux ARM64.  
      2. We updated the cg library to fix the library-loading issue reported in the thread, and the data has been refreshed accordingly. Changes:  
         1. Added libcg.dylib — macOS binary  
         2. Added libcg-arm64.so — Linux ARM64 binary  
      3. There are no changes to main.py, deck.csv, or the rest of the cg API, so existing submissions should be unaffected.  
   2. Simulator update:  
      1. This update is intended to address the issue where games could end in a draw due to the step limit, instead of the looping player eventually losing by timeout.  
      2. Existing scores will be preserved. Under the updated environment, there is now a sufficiently large step limit so that, if a player enters an infinite loop, they should eventually lose by timeout rather than the game ending in a draw.

2. We have also been working on increasing game throughput, and we are gradually increasing the game rate as improvements land. We will share updated game-rate targets once the next round of improvement ship, which we expect in the coming days. We're also continuing to monitor things like how the meta may change by rating band, the number of games required for a submission to achieve a high level of stability, etc. We'll be sure to keep everyone updated with any findings or changes to matchmaking or the post-deadline gameplay.

Best,

Addison
