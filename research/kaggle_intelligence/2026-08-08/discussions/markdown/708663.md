I made a beginner-oriented walkthrough based on the Mega Lucario ex sample rule-based agent notebook.

Notebook:
https://www.kaggle.com/code/ichigoe/beginner-guide-from-deck-list-to-first-valid-sub

Reference notebook:
https://www.kaggle.com/code/kiyotah/a-sample-rule-based-agent-mega-lucario-ex-deck/notebook

The core agent implementation is mostly based on the reference notebook.  
My goal was to add explanations around the Kaggle workflow that may be confusing for first-time participants.

The notebook covers:

- how a deck is represented as 60 Card IDs
- how the deck can be hardcoded directly in the code
- how `deck.csv` can also be used
- how `/kaggle/input` and `/kaggle/working` are used in this competition
- how to create `submission.tar.gz`
- the difference between direct Submit and Save Version → Save & Run All → submit from Output

This is not intended to be a strong solution.  
It is mainly a setup guide to help people reach their first valid submission.

I hope this is useful for first-time participants. If you notice anything confusing or missing, I’d appreciate your suggestions.
