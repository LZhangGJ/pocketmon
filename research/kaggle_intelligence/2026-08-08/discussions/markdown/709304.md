I reran Kiyota's public RL/MCTS sample notebook and summarized the learning curve.

Notebook reference:

https://www.kaggle.com/code/kiyotah/reinforcement-learning-and-mcts-sample-code

What the sample demonstrates:

- It uses the battle API and search API to collect self-play data.
- It trains a small PyTorch value/policy model over five iterations.
- The evaluation win rate in my rerun moved from `18%` to a peak of `74%`, then ended at `60%`.
- The output is five checkpoint files: `model0.pth` through `model4.pth`.

Important caveat:

This notebook does not create a submission agent by itself. It does not output `main.py`, `deck.csv`, or `submission.tar.gz`. To turn this into a competition agent, the model architecture and feature encoding would need to be ported into `main.py`, then validated through battle gates.
