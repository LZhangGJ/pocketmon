# 2026-06-19 Public Meta Snapshot: Top-100 Rank-Band View

Today I expanded the public meta check from the visible top 10 to the visible top 100.

> Caveat: this is only a snapshot from the public Leaderboard / Game History surface.  
> It is not the hidden evaluation distribution, and the meta may change quickly.

I am intentionally keeping this abstract. This post does not include full decklists, replay contents, submission IDs, or concrete counter instructions.

## Summary

The visible top 100 looks less like a single-archetype environment and more like a field with several broad strategic axes.

The rough distribution is:

| Broad axis | Share in visible top 100 | How I read it |
| --- | ---: | --- |
| Fast Fighting tempo | 43% | Still the largest axis |
| Psychic-type control | 20% | Important in the upper ranks |
| Lightning tempo | 19% | Another major pressure point |
| Sustain / wall / long game | 7% | Smaller overall, but risky to ignore |
| Grass engine / midrange | 4% | Minority axis, useful for robustness checks |
| Fire midrange | 2% | Small but present |
| Other / mixed | 5% | Hybrid strategies still appear |

**Main correction from a top-10-only view:**  
Psychic-type and Lightning strategies are important, but across the visible top 100, fast tempo is still the largest broad axis.

## What These Labels Mean

These labels are not exact deck names. They are broad play-pattern buckets inferred from visible public Game History.

| Label | Plain meaning | What I am looking at |
| --- | --- | --- |
| Fast Fighting tempo | A speed-oriented style that builds board early and tries to take prizes quickly | Early setup, low-HP targeting, fast attack start |
| Psychic-type control | A Psychic-type board that also slows the opponent down or pressures resources | Disruption, hand/deck resource management, mid-to-long game control |
| Lightning tempo | A Lightning-type style that keeps attacking and cycling board state | Repeated attacks, energy flow, board cycling |
| Sustain / wall / long game | A style that tries to survive, heal, wall, or win through long-game resource pressure | Healing, deck management, stalling, long-game decisions |
| Grass engine / midrange | A Grass-type setup engine that stabilizes board and fights through the midgame | Setup consistency, midgame damage, staying power |
| Fire midrange | A Fire-type midgame pressure style | Evolution line, midgame comeback, concentrated damage |
| Other / mixed | Hybrid or unusual styles that do not fit cleanly into the buckets above | Mixed axes, unusual card choices |

For example, “Fast Fighting tempo” is not meant to name one exact list. It means a broader style that starts attacking early and tries to pressure the opponent before their board is fully developed.  
Likewise, “Psychic-type control” groups strategies that combine a Psychic-type board with disruption and resource pressure.

## Rank-Band Pattern

The visible meta changes depending on which leaderboard band you inspect.

| Rank band | What stands out | Practical meaning |
| --- | --- | --- |
| 1-10 | Fast tempo is very visible, and Psychic control also appears | Top-end pressure is not only control |
| 11-25 | Fast tempo remains the largest group; Lightning and Psychic both matter | The upper entrance still requires speed tolerance |
| 26-50 | Mixed and engine-based strategies begin to appear | Useful band for detecting overfitting |
| 51-75 | Fast tempo, Lightning, and Psychic all matter | A single average win rate can hide matchup holes |
| 76-100 | Sustain / wall / long-game pressure becomes more visible again | Long-game evaluation should not be removed completely |

## Change From The Previous Top-10 View

The previous top-10 snapshot made Psychic-type control and Lightning tempo look like the main new pressure points.

Expanding to the visible top 100 changes the interpretation:

| Earlier read | Top-100 read |
| --- | --- |
| Psychic and Lightning are increasing | Still true, but fast tempo remains the largest axis |
| Sustain-only assumptions are risky | Still true, but sustain / wall should not be removed from evaluation |
| The top 10 is enough to define the meta | Probably not; different rank bands have different mixtures |

## Evaluation Takeaway

Based on the public view, I would currently split local evaluation into at least four broad axes.

| Axis | What to test |
| --- | --- |
| Fast tempo / early board pressure | Can the agent avoid early board collapse? |
| Psychic-type control / disruption | Can it maintain resources and board state under disruption? |
| Lightning tempo / repeated pressure | Can it handle repeated attacks and board cycling? |
| Sustain / wall / long-game pressure | Can it avoid poor long-game resource decisions? |

This does not mean every agent must beat every axis equally.  
But a single average win rate can hide important matchup holes.

## Practical Note

I would treat this as a scouting snapshot, not a permanent meta conclusion.

The leaderboard may change again tomorrow. The useful part is not locking onto today’s exact percentages, but keeping the habit of checking multiple rank bands instead of only the current top 10.

## Takeaways

- The visible top 100 is multi-axis, not single-archetype.
- Fast tempo is still the largest broad axis.
- Psychic-type and Lightning strategies are important, but they are not the whole field.
- Sustain / wall strategies are smaller overall, but still visible near the top-100 boundary.
- Rank-band evaluation is probably more useful than a top-10-only benchmark.

# 2026-06-19 公開メタスナップショット: 上位100位の順位帯別分析

今日の公開メタ確認では、見えている上位10人だけでなく、上位100位まで範囲を広げて見ました。

> 注意: これは公開リーダーボード / ゲーム履歴から見える範囲だけのスナップショットです。  
> 非公開評価全体の分布ではなく、メタはかなり速く変わる可能性があります。

内容は意図的に抽象化しています。完全なデッキリスト、リプレイの中身、提出ID、具体的な対策手順は含めません。

## 要約

見えている上位100位は、単一アーキタイプ環境というより **複数の軸が混ざった環境** に見えます。

大まかな構成は次の通りです。

| 大まかな軸 | 上位100位での比率 | 見え方 |
| --- | ---: | --- |
| 高速格闘テンポ | 43% | まだ最大勢力 |
| 超タイプ系コントロール | 20% | 上位帯で重要 |
| 雷テンポ | 19% | こちらも大きな圧力 |
| 耐久 / 壁 / 長期戦 | 7% | 全体では少なめだが無視は危険 |
| 草エンジン / 中速 | 4% | 少数だが、頑健性を見る相手になる |
| 炎中速 | 2% | 少数だが存在する |
| その他 / 混成型 | 5% | 混成型も残っている |

**上位10人だけを見たときからの主な修正:**  
超タイプ系と雷テンポは重要ですが、上位100位全体では高速テンポがまだ最大の軸です。

## 用語のざっくり説明

ここで使っている分類は、完全なデッキ名ではなく「公開ゲーム履歴から見えた大まかな戦い方」の分類です。

| 用語 | ざっくり言うと | 見ている特徴 |
| --- | --- | --- |
| 高速格闘テンポ | 序盤から盤面を作って、早めにサイドを取りに行く速攻寄りの型 | 初動の展開、低HP狙い、早い攻撃開始 |
| 超タイプ系コントロール | 超タイプ系の盤面を作りながら、相手の動きを遅らせたりリソースを削ったりする型 | 妨害、手札/山札管理、中長期戦 |
| 雷テンポ | 雷タイプ系の継続攻撃で、テンポよく攻め続ける型 | 攻撃回数、エネルギー供給、盤面回転 |
| 耐久 / 壁 / 長期戦 | 高耐久や回復で粘り、相手のリソース切れや長期戦を狙う型 | 回復、山札管理、時間稼ぎ、長期戦判断 |
| 草エンジン / 中速 | 草タイプ系の展開エンジンで盤面を整え、中盤以降に戦う型 | 展開の安定性、中盤の打点、継戦能力 |
| 炎中速 | 炎タイプ系の中盤以降の打点で押す型 | 進化ライン、中盤の反撃、打点集中 |
| その他 / 混成型 | 上の分類にきれいに収まらない混成・独自型 | 複数軸の混在、特殊なカード選択 |

たとえば「高速格闘テンポ」は、特定の1デッキ名というより、早く攻撃を始めて相手の盤面が整う前に押し切るタイプの総称です。  
「超タイプ系コントロール」も、特定の1リストではなく、超タイプ系の盤面と妨害・リソース管理を使って中長期戦を狙うタイプとしてまとめています。

## 順位帯ごとの見え方

| 順位帯 | 目立つこと | 実用上の意味 |
| --- | --- | --- |
| 1-10位 | 高速テンポがかなり目立ち、超タイプ系コントロールも見える | 最上位の圧力はコントロールだけではない |
| 11-25位 | 高速テンポが最大で、雷と超タイプ系も重要 | 上位入口でも速度耐性が必要 |
| 26-50位 | 混成型やエンジン系が増え始める | 特定相手への過剰適応を見つけやすい |
| 51-75位 | 高速テンポ、雷、超タイプ系がどれも重要 | 平均勝率だけだと弱点を隠しやすい |
| 76-100位 | 耐久 / 壁 / 長期戦の軸がまた見えやすくなる | 長期戦評価を完全に切るのは危険 |

## 評価上の示唆

公開情報から見る限り、ローカル評価では少なくとも次の4軸に分けて見たいです。

| 軸 | 見たいこと |
