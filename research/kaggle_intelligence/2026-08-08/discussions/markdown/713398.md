Hi everyone,

While working on the competition, I found that creating and editing decks manually could be quite time-consuming. Every time I wanted to try a new idea, I had to search for card IDs, edit the CSV by hand, double-check deck legality, and make sure I hadn't made any formatting mistakes.

To make deck iteration easier, I built a small deck-building utility and decided to share it with the community.

### Features

* Browse Pokémon, Trainer, and Energy cards in a simple UI
* Search and filter cards quickly
* View card details while building a deck
* Automatically enforce deck-building rules

  * Maximum 60 cards
  * Maximum 4 copies per card
  * ACE SPEC restrictions
* Export decks directly in the required CSV format

### Repository

[GitHub Repository Link](https://github.com/Ashutosh-agarwal2004/Pokemon-TCG-Competition-Deck-Builder.git)

### Important

* The repository contains only the source code for the tool.
* No competition data, card images, PDFs, or other competition assets are included.
* Users must obtain the official competition data separately and comply with all competition rules.

This is a community tool and is not affiliated with The Pokémon Company, Kaggle, or the competition organizers.

If you encounter any bugs or have suggestions for improvements, feel free to leave feedback or open an issue. I hope it helps make deck experimentation a little faster for everyone.

Good luck in the competition!
